Kebijakan Privasi

Terakhir diperbarui: 18 Oktober 2026

EDWARD GAME (edward-game.vercel.app) adalah game parkur web buatan Edward Maulana Nasution. Halaman ini menjelaskan data apa yang kami kumpulkan dan bagaimana data itu dipakai.

Data yang dikumpulkan

  • Login Google (opsional): saat kamu menekan "Login dengan Google", kami menerima identitas akun Google dasar: ID akun dan alamat email. Kami tidak meminta akses ke Gmail, Drive, kontak, atau data Google lainnya. Kami tidak menerima kata sandi Google kamu.
  • Data permainan: nama pemain yang kamu pilih, skor dan jarak tempuh, serta mode permainan, untuk papan skor global.
  • Data teknis: alamat IP diolah menjadi kode acak (hash) satu arah untuk membatasi spam dan kecurangan. Alamat IP aslinya tidak disimpan.
  • Penyimpanan di perangkatmu: pengaturan, koin, skin, dan kemajuan permainan disimpan di browser (localStorage) dan tetap berada di perangkatmu.

Kegunaan data

  • Menjadikan satu akun Google sebagai satu identitas pemain.
  • Menampilkan nama dan skor di papan skor global.
  • Mencegah kecurangan dan penyalahgunaan layanan.

Email kamu tidak ditampilkan kepada pemain lain dan tidak dijual atau dibagikan untuk iklan. Penggunaan informasi dari Google mematuhi Google API Services User Data Policy, termasuk persyaratan Penggunaan Terbatas.

Penyedia layanan

Data akun dan skor disimpan di Supabase, dan situs ini di-host di Vercel. Keduanya memproses data atas nama kami untuk menjalankan game.

Penghapusan data

Kamu dapat meminta penghapusan akun dan seluruh data skor dengan mengirim email ke alamat kontak di bawah. Kamu juga dapat mencabut akses di pengaturan akun Google kapan saja.

Anak-anak

Game ini ditujukan untuk umum dan tidak secara khusus mengumpulkan data pribadi anak-anak.
