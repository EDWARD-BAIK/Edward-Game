# EDWARD GAME

**EDWARD GAME** adalah game parkur lintas dimensi berbasis web, dikembangkan oleh **Edward Maulana Nasution**.

🎮 **Main sekarang:** https://edward-game.vercel.app

## Fitur

- **Parkur lintas dimensi**: puluhan dimensi dengan tema berbeda, bisa dipilih manual atau diacak
- **Dua mode**: Normal dan Sulit (musuh, platform rapuh, nyawa lebih sedikit)
- **Toko skin**: banyak skin karakter yang dibeli dengan koin hasil bermain
- **Papan skor**: rekor jarak terbaik
- **Misi harian dan pencapaian** dengan hadiah koin
- **Multiplayer** lewat ID room atau link undangan
- **Pengaturan**: musik, efek suara, partikel, guncangan layar, dan getaran

## Kontrol

| Aksi | Keyboard | HP |
|------|----------|----|
| Gerak | A / D atau ← / → | Tombol ◀ ▶ |
| Lompat (bisa 2x di mode Normal) | Spasi / W / ↑ | Tombol LOMPAT |
| Dash | E / Shift | Tombol DASH |
| Jeda / Pengaturan | Esc | Tombol ⚙ |

## Teknologi

HTML, CSS, JavaScript (Canvas), PeerJS untuk multiplayer, dan di-hosting di Vercel.
